Html(hypertext markup language) - is the code that is used to structure a webpage and its content.

<li>text<li> this is used for bullet points

<!doctype html> -required so document behaves correctly

<html></html> - wraps all the content of the page, sometimes
know as the root element. It can include lang attribute for language.


<head></head> - for the part of html content that your page viewers wont see.
Used for keywords and page description that will appear in search results.
Css to style the content, character set and more.


<meta charset="utf-8"/> - this is used to allow all kinds of symbols. For example
so many languages could be written.

<meta name="viewport" content="width=device-width"> - The viewport element is 
used so that when viewing the page on a smaller device it wont render wider page
than it should have to.

<title></title> - The name of the page on your browser at the top higher than search
bar.

<body></body> - All the content that you want to show to page viewers.

Most element consisting of opening tag and closing tag, but some can have inside thme
attributes. Like lang, src.

<img> - in this element the src attribute is used to put in the file path of image.
and the alt attribute is for accessibility can specify what is the name of the image
for blind people.

<img> elements have no content and no closing tag so they are called empty or void elements

Most common lists in html are unordered list and ordered lists.

ordered lists - where order matters, list of numbers. used element <ol>
