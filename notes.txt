You can link to a file in the same directory by just specifing the file name.

What is a table?

A table that is made up of data in rows and columns.

A table lets you find values that have a connection with each other.

For example:
Person name & age.

When tables are created well, screen reader should be able to read it correctly.

Tables are used for data that is easy to work in rows and columns.

Its bad practice to use tables for headers, contents. Earlier it was used becaause css styling was not
accessible to use.

Tables layout generally produce more complex code that is harder to maintain. 

Its bad for the screen reader to read.

Tables are not automatically responsive to smaller/ bigger devices. they dont resize.
Like other elements do.

Every table is encloses with tags <table></table>

The smallest container inside a table is called a table cell.
Its created by using the  element <td></td> (short for table data)

If we want a couple of cells in a row of table data, then just need to copy paste acouple td elements.
For example:

<td></td>
<td></td>
<td></td>
This be a row of three cells that are aligned to each other.

To create a new row of cells need to use the tr element <tr></tr> as a wrapper around the cells of the row
For example: this is a row of three cells

<td></td>
<td></td>
<td></td>
</tr>

You can use th element to create table header
For example
There is people names and ages so it would be more understable at the beggining
write table headers with word age and another with name

        <tr>
            <th>Name</th>
