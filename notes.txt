The flex model

the main axis is  the direction that the flex ites are layouded. for example rows vertically
columns horizontally

the starting points of the main axis is called the main start and the main end.

the flex item size layout in the main axis direction is called the main size.

the cross axis is the 90 degree angle as a line to flex items layout.

The start and end points of cross axis are called cross start and cross end.

the lenght of the flex item along the cross axis is called cross size.

the element that has the display:flex applied is called the flex container.

in the flex container the elements are called flex items.



Columns or rows?

the default direction of your flex item is left to right or like rows.

its possible to change with flex-direction: column; the direction of the items to go vertically.

flex-direction: row-reverse; changes where items start from start from right to left.
flex-direction: column-reverse; reverses the columns positions.

Implicit and explicit grids

explicit grid are grid create with grid-template-columns, grid-template-rows.

implicit grids: extend the implicit grid when the content is placed outside of the grid.
by drawing more grid lines .

content created in implicit grid on default is auto-sized, that means they are large enough to hold
their content.

its possible to change their auto sizing by using grid-auto-rows and grid-auto-columns.

if you add grid-auto-rows: 100px; its not really 100 pixels tall.


The minmax() function

the 100 tall pixel rows are not really useful if their content is larger than the rows. So its better
to have rows that are atleast 100 pixels tall but can expand.

minmax() - lets you say how much pixels is on default and then can give another value that is auto.
That will automatically make it bigger if there is more content.

grid-auto-rows: minmax(50px, auto); now if extra content is added it expands.



As many columns as will fit

Sometimes its useful to create as many columns as the contatiner can hold.
That is possible by using the minmax, repeat and auto-fix.

grid-template-columns: repeat(auto-fix, minmax(230px, 1fr));

really useful for solving a lot of resposive desing problems.

so repeat takes auto-fix as a value and that repeats untill the container is full, by the specified
minmax values 230px is default, and the largest is 1fr which just takes all the space and evenly dis
tributes to all the boxes.
