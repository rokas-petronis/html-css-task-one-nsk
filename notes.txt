For example.
A call for action so people would unite to this charity.


Linking in the same directory.

You can link to a file in the same directory by just specifing the file name.

<a href ="question-and-answer.html">QA link</a>

Its also possible to use ./ for more clarity. Some people like it more. But they are both the same.

For example it would look like this href="./question-and-answer.html"


Moving down directories - its possible to go down the main directory subdirectory by specifying
the the directory followed by a forward slash and the filename you want from the subfolder.

For example:

<a href="images/apelsinas.png">This is a link to a orange image</a>


You can specify a link from one subdirectory to another subdirectory by going back to the root directory

you do that by using the ../ before the subdirectory u want to link with the directoryname, and filename.

for example.

if you want to link in a landing-page/index.html filename a subdirectory of root folder 
u go to root folder <a href="../images/bananas.png">Link to a banana page in a a subfolder of root directory</a>

By using the links u can create a link from the landing page back to the homepage. Just need to use
a forward slash before the name of the index.html if the mainpage index.html is in the root directory.
